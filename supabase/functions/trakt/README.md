# Trakt Edge Function (legacy)

This Edge Function is inactive and is not used by the current tvOS app. The app
stores Trakt credentials per profile and performs OAuth and Trakt API requests
directly with Trakt.

The former endpoint, `https://api.nuvio.tv/functions/v1/trakt`, currently returns
404. This directory is retained as legacy code; its old deployment and account
session instructions no longer apply. See [Supported Tracking Services](../../../README.md#supported-tracking-services)
for the current app overview.
